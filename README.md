# Discord Forum Archive

为 Discord 网页版论坛帖子保存独立的本地收藏。原生关注取消、成员身份被 Bot 移除、帖子归档或暂时不可访问，都不会删除已经保存的收藏。

**当前发布版本：1.0.1（main）。修复候选版已合并；尚未完成真实 Discord/Tampermonkey 集成与视觉验收。原生关注捕获仍属于实验性功能：新资料库默认开启，已有资料库保留原设置。**

## 安装

1. 在桌面浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。允许其运行用户脚本；Chromium 浏览器可能需要启用扩展的“允许用户脚本”或开发者模式，具体以扩展提示为准。
2. 打开 [安装 Discord Forum Archive](https://raw.githubusercontent.com/FangInJapan/Discord-Forum-Archive/main/dist/discord-forum-archive.user.js)，在 Tampermonkey 安装页确认。
3. 若浏览器只显示源码，下载 `dist/discord-forum-archive.user.js`，在 Tampermonkey 管理面板的“实用工具 → 从文件导入”安装。
4. 打开 Discord 网页版的 `/channels/…` 页面并刷新一次。支持 `discord.com`、`canary.discord.com` 和 `ptb.discord.com`；不支持 Discord 桌面客户端。
5. 首次创建或选择资料库后会记住选择，刷新自动恢复。要切换账号，请使用 Tampermonkey 扩展菜单中的“切换本地资料库 / 账号”。

脚本不需要 Node.js、后端或 Discord Bot。Node.js 只用于源码开发与测试。

## 使用

- **收藏当前帖子**：进入能识别的帖子，点击面板“收藏当前帖子”。折叠面板时另有独立收藏入口。已收藏时打开管理界面，不会一按就删除。
- **添加链接**：点标题栏 `+`，粘贴帖子永久链接，并确认它属于论坛帖子。带消息 ID 的链接只取频道位置的 ID，最后的消息 ID 不作为帖子 ID。URL 本身不能证明频道类型，因此需要你的确认。
- **待归属**：不知道父论坛时留空。之后点“编辑”，填入正确父论坛 ID 和名称。不会默认放进当时正在浏览的论坛。
- **查找与整理**：选择“本频道 / 待归属”或“整个服务器”，按标题或论坛名搜索；支持收藏时间、修改时间、自然标题顺序及星标优先。每个服务器各自记忆范围与排序。
- **重命名**：修改本地自定义标题，原始标题另行保留；可勾选恢复原始标题。只在看到可识别的新标题时更新原始标题，不后台获取回复或远端活跃时间。
- **删除**：有确认框，仅删除本地收藏，不改变 Discord 帖子或关注关系。
- **备份**：面板底部“备份 / 恢复”导出 JSON。导入先显示有效数量，再选择冲突策略并确认；默认保留本地已有记录。备份包含本资料库全部服务器的记录。
- **调整面板**：拖标题栏移动；拖边框或四角缩放。靠近四边 24 px 时吸附；可在设置关闭。上、下停靠仍使用纵向列表。
- **长标题**：设置内可选 1–4 行或完整显示，每条收藏还可独立展开全文。标题 12–22 px、界面 11–18 px，均按 1 px 调整；支持三种密度。
- **主题**：默认读取 Discord 可用 CSS 变量，主题变化会更新；可强制深色或浅色。复杂渐变使用近似纯色。
- **折叠 / 隐藏**：`−` 折叠成书签标签，`×` 完全隐藏；从 Tampermonkey 菜单“显示 Forum Archive”恢复。私信默认不显示浮动面板，普通或未识别频道默认折叠。手动折叠/隐藏偏好会保留。
- **切换账号**：点资料库名称手动切换。脚本无法可靠识别当前 Discord 账号，**不会读取 Token 来识别账号**；同一标签页切换账号后，须由你通过 Tampermonkey 菜单选择对应资料库。

## 原生关注自动记录

新资料库默认启用实验性开关；既有资料库如已保存关闭状态，请在设置中手动开启。开启后，只观察你对当前帖子的明确操作：原关注按钮必须仍是同一控件、已变为退出/取消关注状态，并稳定至少 650 ms。当前路由、帖子或资料库变化会取消待确认捕获。

中文、日文、英文标签规则已做模拟测试，**没有经过真实 Discord 多语言实测**。右键菜单、按钮被替换、只有图标或缺少可靠可见信号时不会自动保存。页面短暂显示成功、服务器稍后回滚等情况仍可能误判；此功能无法确认服务器最终状态。请以本地收藏列表为准，必要时手动收藏。

不会通过发言自动加入、自动发帖保活、批量关注、获取 Token 或调用私有接口来补足识别能力。

明确删除过的本地收藏不会被后续自动捕获恢复；需要时请手动重新收藏。

## 数据与并发

收藏身份为字符串 `guildId + threadId`。数据写入 Tampermonkey 的持久存储；每次新增、字段修改或删除都写入独立、唯一的变更键，读回确认后才显示成功。不会整库覆盖。

多个标签页通过变更通知与 5 秒可见页轮询合并操作。不同帖子和不同字段的修改可以合并；同一字段冲突按逻辑时钟及标签页标识确定唯一顺序。删除后的观察或字段修改不能复活记录，明确重新添加才可以。Tampermonkey 没有事务/CAS 接口，因此不能保证严格线性一致性；偏好设置使用最后写入者生效，详见 [架构说明](docs/ARCHITECTURE.md)。

变更日志不会自动压缩或清理，避免跨标签页回放丢失；频繁编辑时体积会增长。请定期导出 JSON 并保留扩展备份。卸载脚本、清理扩展数据或浏览器资料损坏可能丢失本地数据。

## 已知兼容限制

- 页面识别只读取可见 DOM、语义属性、少量线程侧栏类名片段与 URL；不会访问 Discord 内部 store。DOM 改版可能导致论坛或帖子无法识别。这时通过 `+` 手动添加仍可使用。
- 仅当从已识别论坛内的帖子链接进入，或已有本地明确归属时，才自动认定父频道。无链接结构的卡片、直接进入的帖子等可能显示待归属。
- 不能找回安装脚本前已经失去关注、且没有本地记录的帖子；也不保证能访问已删除或失去权限的原帖。
- 字符串标题最大 20,000 个 UTF-16 代码单元，超过则明确拒绝，绝不静默截断。导入最大 10 MiB、10,000 条记录；格式不支持时整份拒绝。
- 导入分条保存，不具备整批事务。写入中断会明确报错，保留已导入记录，可重试并去重。
- 跨标签页、主题、拖动缩放和列表功能已实现，但本次没有真实浏览器渲染或 Tampermonkey 实机测试。见 [验收记录与复现步骤](docs/TESTING.md)。

## 开发

Node.js 20 或更高。运行构建和逻辑测试不需要安装依赖：

```sh
npm test
npm run build
npm run check
```

源码在 `src/`，确定性构建输出为 `dist/discord-forum-archive.user.js`，没有运行时外部依赖。

可选浏览器夹具测试（需要浏览器下载网络）：

```sh
npm install
npx playwright install chromium
npm run test:browser
```

该测试针对模拟 DOM，不代表真实 Discord 集成验收。也可以运行 `node test/make-fixture.mjs` 后自行在本地打开生成的测试页，测试数据与产品 GM 存储分离。

实现计划、模块边界和数据格式见 [ARCHITECTURE.md](docs/ARCHITECTURE.md)；20 项需求验收映射见 [TESTING.md](docs/TESTING.md)。

## 隐私与项目性质

不读取或保存 Token、Cookie 等凭据；不发起 Discord API 请求、不上传收藏、不加载远程代码。脚本更新由 Tampermonkey 按元数据中的 GitHub 地址检查。

这是非官方的网页注入工具，Discord 更新可能破坏兼容性，使用者需自行考虑平台服务规则风险；不代表 Discord 官方许可或背书。
