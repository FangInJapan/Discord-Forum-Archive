# Discord Forum Archive

**V1.1.1 · 中文界面 · Tampermonkey · 本地收藏**

独立保存 Discord 论坛帖子：被 Bot 移出或取消原生关注时，本地收藏不会自动删除。

## 安装

[从 main 分支安装 / 更新](https://raw.githubusercontent.com/FangInJapan/Discord-Forum-Archive/main/dist/discord-forum-archive.user.js)。仅支持 Discord 网页版。更新前建议从 Tampermonkey 菜单导出 JSON 备份。

## 主要交互

- **一键收藏**：打开帖子，点「收藏当前帖子」，直接加入当前收藏夹，不再弹出字段表单。父论坛未知则暂存为待归属。
- **手动链接**：面板顶部「+」或 Tampermonkey 菜单「通过链接添加帖子」，只需链接；可选填标题。
- **三列工具栏**：左边切换本频道 / 全服务器；中间选择收藏夹、管理收藏夹；右边图标式排序。
- **收藏夹**：新建、重命名、删除，删除收藏夹时将其中帖子转移到默认收藏夹。所选收藏夹同时用于筛选和决定新收藏目标。
- **紧凑行**：星标、短时间、标题、三点菜单。三点菜单包括重新读取标题、编辑（含移动收藏夹）、复制链接和删除。
- **自定义服务器及论坛名**：点击上方服务器 / 论坛标题修改本地显示名称，不改变 Discord 原名。
- **标题刷新**：底部「更新可见标题」只检查当前 Discord 页面已显示的帖子，60 秒冷却；不会在后台逐一访问全部收藏帖。
- **设置**：面板宽、高使用百分比滑条（百分比指可调整尺寸范围）；继续支持字号、长标题、颜色跟随、吸附、折叠和隐藏。
- **低频操作**：资料库切换与 JSON 备份恢复移到 Tampermonkey 扩展菜单，刷新记住已选资料库。

## 数据兼容

保留旧版操作日志前缀 dfa:v1:，不清空旧数据。没有收藏夹字段的旧收藏自动归入「默认收藏夹」。V1.1 新增收藏夹 ID、用户别名以及本地标题记录时间字段。JSON 备份包含收藏夹和别名；旧格式可以继续导入。

短时间代表**本地首次记录或观察到标题变化**的时间，不等于 Discord 服务器端实时修改时间。未获得可靠时间时显示「—」。

## 原生关注与导入

目前只针对**中文 Discord 页面**适配。原生关注自动记录仍为实验性功能，只有可确认的可见 UI 状态才会触发。Tampermonkey 菜单支持尝试导入当前已渲染的明确已关注帖子，但不保证找回历史所有帖子。

没有引入上传参考脚本中的 Token 提取、Discord 私有 API、自动发言或后台采集功能。

## 开发

Node.js 20+。执行 npm test、npm run build、npm run check。构建后的单文件位于 dist/discord-forum-archive.user.js。

源代码：src/core.js、src/discord.js、src/app.js、src/style.js；构建脚本：scripts/build.mjs；测试：test/。

**验证说明**：当前已对语法、数据迁移与基本收藏夹逻辑进行检查；真实登录 Discord 后的 UI/关注兼容性仍需实测，不能把模拟测试当成实机通过。

## V1.1.1 输入焦点修复

修复 Discord 帖子页面中，Forum Archive 搜索框或弹窗输入获得焦点后，按键仍被 Discord 聊天编辑器接收的问题。脚本在 Shadow DOM 边界隔离键盘、输入法组合、粘贴及焦点事件，并在面板内部可编辑控件获得焦点时临时标记宿主可编辑，以避免外部快捷键监听器误判。

不阻止输入控件的浏览器默认行为，也不影响面板内的快捷键、Enter 提交、Esc 关闭、Tab 切换或中文输入法组合。离开输入框后恢复宿主状态，不应阻止 Discord 编辑器正常输入。

自动化校验包含可执行的事件隔离单元测试及模拟 Discord 全局捕获阶段快捷键的 Chromium 浏览器测试。真实 Discord 不同客户端版本中的快捷键实现可能不同，仍需在实际帖子页面验证。
