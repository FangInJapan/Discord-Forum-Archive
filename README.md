# Discord Forum Archive

**V1.3.3 · 中文界面 · Tampermonkey · 本地收藏**

独立保存 Discord 论坛帖子：被 Bot 移出或取消原生关注时，本地收藏不会自动删除。

## 安装

[从 main 分支安装 / 更新](https://raw.githubusercontent.com/FangInJapan/Discord-Forum-Archive/main/dist/discord-forum-archive.user.js)。仅支持 Discord 网页版。更新前建议从 Tampermonkey 菜单导出 JSON 备份。

## 主要交互

- **一键收藏**：打开帖子，点「收藏当前帖子」，直接加入当前收藏夹，不再弹出字段表单。父论坛未知则暂存为待归属。
- **手动链接**：面板顶部「+」或 Tampermonkey 菜单「通过链接添加帖子」，只需链接；可选填标题。
- **三列工具栏**：左边切换本频道 / 全服务器；中间选择收藏夹、管理收藏夹；右边图标式排序。
- **收藏夹**：新建、重命名、删除，删除收藏夹时将其中帖子转移到默认收藏夹。所选收藏夹同时用于筛选和决定新收藏目标。
- **紧凑行**：星标、短时间、标题、三点菜单。三点菜单包括重新读取标题、编辑（含移动收藏夹）、复制链接和删除。
- **自定义服务器及论坛名**：点击上方服务器 / 论坛标题修改本地显示名称，不改变 Discord 原名。
- **标题刷新**：底部「更新可见标题」只检查当前 Discord 页面已显示的帖子，60 秒冷却；不会在后台逐一访问全部收藏帖。
- **设置**：面板宽、高使用百分比滑条（百分比指可调整尺寸范围）；继续支持字号、长标题、颜色跟随、吸附、折叠和隐藏。
- **低频操作**：资料库切换与 JSON 备份恢复移到 Tampermonkey 扩展菜单，刷新记住已选资料库。

## 数据兼容

保留旧版操作日志前缀 dfa:v1:，不清空旧数据。没有收藏夹字段的旧收藏自动归入「默认收藏夹」。V1.1 新增收藏夹 ID、用户别名以及本地标题记录时间字段。JSON 备份包含收藏夹和别名；旧格式可以继续导入。

短时间代表**本地首次记录或观察到标题变化**的时间，不等于 Discord 服务器端实时修改时间。未获得可靠时间时显示「—」。

## 原生关注与导入

目前只针对**中文 Discord 页面**适配。原生关注自动记录仍为实验性功能，只有可确认的可见 UI 状态才会触发。Tampermonkey 菜单支持尝试导入当前已渲染的明确已关注帖子，但不保证找回历史所有帖子。

没有引入上传参考脚本中的 Token 提取、Discord 私有 API、自动发言或后台采集功能。

## V1.1.1 输入焦点修复

修复 Discord 帖子页面中，Forum Archive 搜索框或弹窗输入获得焦点后，按键仍被 Discord 聊天编辑器接收的问题。脚本在 Shadow DOM 边界隔离键盘、输入法组合、粘贴及焦点事件，并在面板内部可编辑控件获得焦点时临时标记宿主可编辑，以避免外部快捷键监听器误判。

不阻止输入控件的浏览器默认行为，也不影响面板内的快捷键、Enter 提交、Esc 关闭、Tab 切换或中文输入法组合。离开输入框后恢复宿主状态，不应阻止 Discord 编辑器正常输入。

自动化校验包含可执行的事件隔离单元测试及模拟 Discord 全局捕获阶段快捷键的 Chromium 浏览器测试。真实 Discord 不同客户端版本中的快捷键实现可能不同，仍需在实际帖子页面验证。

## V1.2.0：标题变更与玻璃界面

- 面板的展开、折叠和隐藏属于用户手动状态。切换论坛帖子、Discord SPA 暂时出现未知路由时，不再自行折叠或展开。私信页面可以临时隐藏，返回服务器恢复原模式。
- 顶部工具栏增加「全部 / 最近更新」开关。只显示**在本地确认帖子原标题发生变化且尚未标记为已查看**的帖子。第一次保存、无真实标题的占位记录不会被误标。其余服务器/频道/收藏夹筛选仍同时生效。
- 标题变化保留上一次观察的原标题、变化时间、未读标记。帖子三点菜单中可选择「标记标题变化为已查看」。不会因点击普通帖子而自动丢失标记。
- 主题继续跟随 Discord，可在设置页开启或关闭轻量玻璃效果与动效。面板毛玻璃仅在浏览器支持时启用，仍提供纯色降级；响应系统减少动态效果偏好。
- 设置页为「外观 / 布局 / 收藏 / 关于」四个分组，底部固定保存；可以在更短的弹窗内快速查找选项。原有资料库、收藏夹、标签、标题及备份无需手动迁移。
- 标题变化仅在**当前可见帖子**被实际观察到时更新；本脚本不自动请求、批量抓取或后台轮询 Discord 远端标题。历史未被再次观察的帖子不会凭空出现在「最近更新」。
- 旧版 JSON 的新字段默认为「未变化」。新备份保留标题变更状态，导入时仍遵守已有收藏覆盖策略。

自动化校验无法替代实际登录的 Discord UI 验收；建议升级前导出备份，在论坛中检查常用中文主题下的视觉效果。

## V1.2.1：论坛列表可见标题刷新修复

- 修复在论坛列表页点击「更新可见标题」却读不到帖子标题的问题。兼容列表中 `/channels/服务器/帖子` 和 `/channels/服务器/父论坛/帖子` 两种可见链接写法，只有在父论坛可确认时才将第三个 ID 当成帖子 ID。
- 优先读取对应论坛帖子卡片里的标题节点，不把预览正文、消息和操作按钮文字拼进标题。
- 论坛列表仍显示在已打开帖子侧边栏后面、且能确认父论坛时，也能同时读取这些已渲染卡片。
- 点击更新后显示「识别到的帖子数 / 匹配的本地收藏数 / 真正变化的标题数」。如果当前没有可读取的帖子，明确提示先打开论坛并加载列表。没有检查到本地记录时不会启动一分钟冷却。
- 更新**仅使用 Discord 当前网页实际渲染的论坛帖子卡片和当前打开的帖子**，不会访问未加载的帖子，也不会绕过权限或后台逐帖请求。因此即使面板展示了 100 条历史收藏，只有同时存在于当前 Discord 页面 DOM 的帖子才能批量更新。
- 增加覆盖多段链接、带预览卡片和不进入帖子就检测标题变化的回归测试。

## V1.3.0：三个收藏视图与论坛活跃帖手动扫描

在**论坛频道**中点击「更新可见标题」，脚本只检查 Discord 网页已经渲染的活跃帖子卡片，并与本地收藏对比。无法安装 Bot 也能使用，完全不调用用户 Token、非公开 API 或后台抓取。

顶部原来的「本频道/全服务器」与「全部/最近更新」两个开关已合并为 **全部｜更新｜未检测到** 三段滑块：

- **全部**：当前服务器、当前选中收藏夹中的所有收藏（包括不同论坛和待归属帖子）。
- **更新**：当前服务器中，已可靠观察到**标题确实改变**且尚未标记为已查看的收藏。
- **未检测到**：当前服务器已执行过手动扫描的论坛中，*上一次扫描时*没有出现在**已经加载的活跃帖子卡片**内的收藏。未扫描过的论坛不会进入此列表。扫描不同论坛时，按论坛分别记录并汇总此视图。

**特别注意：**「未检测到」不代表帖子失效、已删除、被 Bot 移出或你没有权限。论坛可能归档旧帖、只加载部分卡片、存在分页或虚拟列表。即使未检测到，也绝不自动删除、取消收藏或修改 Discord 的帖子。

扫描会报告当前论坛已加载的帖子数量、匹配本地收藏数、标题变化数和本次未检测到数。如果没有识别到任何活跃帖子，**不会生成或覆盖扫描结果**。重复扫描有单论坛 10 秒冷却；扫描另一个论坛不受该冷却影响。旧收藏和 JSON 备份兼容，扫描快照仅存于本地资料库设置中，不包含在以前的 JSON 备份格式里。

## V1.3.1：论坛识别稳定性修复

Discord 的论坛频道、普通频道和论坛帖子可能同样使用 `/channels/服务器ID/频道ID` 路径，单靠 URL 不足以判定页面类型。为避免论坛已打开却无法点击更新，识别改为「帖子侧栏证据 + 页面论坛证据 + 本地已知论坛 + 人工纠错」组合。

- 已确认的论坛 ID 保存在当前本地资料库的设置中；页面加载后自动恢复。检测到明确论坛列表或创建帖子入口时，自动记住该论坛。已收藏帖子中保存的父论坛 ID 仍可辅助识别。
- 如果点击「更新可见标题」时无法识别论坛，提供**「确认当前频道是论坛」**窗口；只需要确认一次。确认成功后会继续执行可见活跃帖扫描，无需安装 Bot。
- 点击面板中服务器／频道名称 →「频道类型识别 / 修正」，可以选择「确认当前频道是论坛」「这不是论坛（纠正误识别）」或「恢复自动识别」。人工标记非论坛后不会被启发式自动覆盖。
- 修复论坛卡片上的 `data-thread-id` 被错误当作已打开帖子侧栏的情况。真正的帖子侧栏和显式 `?thread=` 查询仍优先视作帖子。
- 如果是人工确认的论坛，即使 Discord 没有渲染旧版论坛专用 CSS 类名，仍可以从当前页面中的明确帖子链接和卡片标题扫描。未加载或无明确链接的卡片无法凭空读取，零条结果不会保存“未检测到”快照。
- 新增论坛登记数据包含在 JSON 备份；旧版备份没有该字段时自动按空登记读取，现有收藏和「全部／更新／未检测到」分类不受影响。登记只影响当前浏览器的资料库，不更改 Discord 频道本身。

此版本不调用 Bot、账号 Token、客户端内部状态或私有 API；代码通过模拟 Discord 页面测试，真实 Discord 页面仍需使用者验收。

## V1.3.2：收藏列表跳转后保持滚动位置

- 修复在 Forum Archive 面板中点击收藏帖后，Discord 切换到对应帖子时收藏列表重新滚到顶部的问题。
- 收藏列表的滚动位置现在以当前服务器为单位保留，不再按当前论坛或帖子 URL 分开管理；切换同服务器的帖子或频道时保留位置、搜索词以及“继续显示”页数。进入其他服务器仍可恢复该服务器上一次的列表位置，搜索则按原逻辑重置。
- 点击收藏标题时额外记录一次滚动快照。Discord SPA 内跳转和短时间内的同步重绘不会覆盖这次快照。
- 如果点击链接导致浏览器在**当前标签页整页重载**，使用短期有效的 `sessionStorage` 快照恢复滚动位置、搜索词和当前已显示数量。读取后立即清除；不跨标签页或长期保存，不改变收藏数据库与原有资料库格式。
- 不修改此前的论坛频道识别逻辑、收藏记录、更新状态或视觉主题。
- Chromium 回归测试覆盖真正非零滚动位置下的收藏点击、页面同步和同标签页重载。

如果某个收藏夹中的记录在跳转时发生了变化，浏览器仍可能将滚动位置限制在新列表实际可滚动的范围内，这是正常行为。

## V1.3.3：当前打开帖子高亮与无刷新导航

Discord 是单页应用，切换帖子时通常通过客户端路由更新 URL 和消息内容，而不是整页重新加载。旧版脚本在观察到路由变化后，固定调用 `renderList()`，用新的 DOM 节点替换整个收藏列表，因此面板看起来像被刷新。

- 现在**同一服务器内切换频道／帖子**时，不再无条件重建收藏卡片；只更新当前服务器／帖子上下文，以及当前帖高亮。真正切换服务器、修改收藏或变更筛选时仍会按需重绘。
- 如果打开的帖子已保存在当前本地资料库，并且出现在目前的「全部 / 更新 / 未检测到」与收藏夹筛选结果中，列表对应条目会显示 Discord 强调色描边、柔和背景以及「正在浏览」标记，链接同时标注无障碍属性 `aria-current="page"`。
- 打开另一个已收藏帖子时，高亮自动移到新帖子；返回论坛频道或打开未收藏帖子时清除高亮。对直接帖子链接暂未被 DOM 正确识别、但 ID 已收藏的情况，也能按 URL ID 保守匹配。
- **不会自动滚动到高亮条目**，保留 V1.3.2 的滚动位置、搜索、收藏夹和分页状态。被当前筛选隐藏的已收藏帖子不会强行插入列表。
- 与已修改标题的提示、星标、玻璃背景和减少动态效果设置兼容。不新增数据库字段、后台网络访问或 Discord API 调用。
- 新增 Node 与 Chromium 模拟页面回归测试：打开已收藏帖子、切换另一个收藏、返回论坛、DOM 节点复用以及保持滚动位置。

注意：仅在真实浏览器打开了可识别的帖子或链接 ID 匹配本地收藏时显示高亮；模拟环境测试通过并不等同于已经在登录状态的 Discord 上验收。
